# Contributing to saacchq.org

sa/acc is a community project. You can improve the website, translations, accessibility, or design. Join our [Discord](https://discord.gg/Ks4Dpdzkmn) to meet the community.

## Run the site

Install Node 22+ and pnpm, then run:

```bash
pnpm install
pnpm dev
pnpm build
```

The site builds without credentials or external services.

## Submit a change

Open a pull request against `main`. Check the English and Arabic versions in the local preview and confirm `pnpm build` passes. The repository runs the same build in CI.
